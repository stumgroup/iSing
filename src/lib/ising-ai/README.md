# iSing AI Core
Single in-house orchestration layer for Music AI, Voice AI and Video AI.
Interfaces: WhatsApp and Website. Persistence: Supabase. Payments unlock full assets.
No ACE-Step, Suno, Udio, or external generation API is required by the application orchestration layer.
The neural models are a training/inference workstream; production must only advertise generated assets when an inference worker has completed them.
